cd [nome de um diretório; entre aspas, caso exista ao menos um espaço no nome] — muda pro diretório especificado (change directory)
	cd .. — volta pro diretório anterior na hierarquia de arquivos
	cd - — volta pro último diretório acessado
	cd OU cd ~ — vai pro diretório-base do usuário
	cd / — vai pro diretório-base do sistema como um todo (também chamado de raiz)

ls — lista o conteúdo do diretório atual (list)
	ls -l — faz a listagem com maiores detalhes
		ls -lh — converte tamanhos de arquivo pra MB/GB/... ao invés de exibir em bytes
	ls -a — mostra arquivos ocultos

chmod — altera permissões de arquivos e diretórios (change mode); sintaxe é chmod [tipo de usuário][mudança a ser feita][permissão a ser alterada] [nome do arquivo/diretório] na forma 1, e chmod [permissões pro primeiro tipo de usuário][permissões pro segundo tipo de usuário][permissões pro terceiro tipo de usuário] [nome do arquivo/diretório] na forma 2
	tipos de usuário — dono do arquivo (user/u), grupo ao qual o arquivo pertence (group/g), demais usuários do sistema (others/o) ou todos simultaneamente (all/a)
	mudanças a serem feitas — adicionar (+) ou remover (-) permissões
	permissões a serem alteradas — ler (read/r/4), escrever (write/w/2) e executar (execute/x/1); na forma 2, as permissões são somadas (por exemplo, rwx = 4 + 2 + 1 = 7), sendo que 0 tira todas elas

ps — lista o status dos processos do usuário atualmente logado (process status)
	ps a — mostra o status dos processos de todos os usuários
	ps u — mostra os donos e o consumo de recursos dos processos
	ps x — mostra o status dos processos iniciados pelo sistema
	ps -ef — mostra tudo aquilo que é exibido em ps aux + o ID dos processos-pai de cada processo

| — chamado de pipe, é usado para executar vários comandos a partir de uma única instrução (exemplo: [comando 1] | [comando 2])

mkdir [nome do novo diretório] — cria um diretório (make directory); caso múltiplos nomes sejam passados em sequência, múltiplos diretórios são criados
	mkdir -p [árvore de diretórios] — cria diretórios aninhados (exemplo: x/y/z)

rmdir [nome de um diretório] — remove um diretório (remove directory); não funciona caso o diretório tenha arquivos

rm [nome de um arquivo] — remove um arquivo; caso múltiplos arquivos sejam passados em sequência, todos são deletados
	rm -r [nome de um diretório] — remove um diretório e todos seus arquivos
	rm -f [nome de um arquivo/diretório] — faz a remoção sem pedir confirmação do usuário
	rm -i [nome de uma sequência de arquivos/diretório] — pede confirmação individual pra cada arquivo a ser deletado, caso haja mais de um

su — muda o usuário ativo (switch user); por padrão, o novo usuário será o superusuário/administrador/root, mas pode-se especificar o usuário com su [nome do usuário]
	su - — muda o usuário sem manter as configurações do usuário anterior

sudo [instrução] — executa uma instrução como superusuário (superuser do)
	sudo !! — executa a última instrução novamente, adicionando o sudo

exit — fecha a atual sessão do terminal (exit); também é utilizado pra voltar ao usuário padrão após um su e pra fechar uma conexão remota após um ssh

man [nome de um comando] — abre a página do manual referente a um determinado comando
	man -k [termo] OU apropos [termo] — busca comandos existentes por palavras-chave
	man -f [nome de um comando] OU whatis [nome de um comando] — mostra um resumo de uma linha de um determinado comando

grep [termo, entre aspas] [nome de um arquivo] — busca uma palavra-chave dentro de um determinado arquivo (globally search for a regular expression and print)
	grep -i [...] — ignora case sensitivity
	grep -c [...] — conta quantas vezes o termo buscado aparece ao invés de mostrá-lo
	grep -n [...] — mostra a linha exata onde o termo foi encontrado
	grep -v [...] — inverte a busca e mostra todas as linhas nas quais o termo buscado NÃO aparece
	grep -r [termo, entre aspas] [árvore de diretórios] — faz a busca em todos os arquivos dentro de uma determinada árvore de diretórios

*.[extensão de arquivos] — pode ser utilizado no lugar de nomes de determinados arquivos para indicar que um comando deve ser executado em todos os arquivos com uma determinada extensão

kill [tipo de sinal, precedido por traço] [ID do processo; pode ser encontrado através do ps] — envia um determinado sinal para um processo; existem um total de 64, mas apenas alguns são relevantes
	sinal 1 — reinicia configurações (SIGHUP)
	sinal 2 — interrompe a atividade atual do processo e fecha (SIGINT)
	sinal 3 — fecha e gera arquivo de log (SIGQUIT)
	sinal 9 — fecha sem salvar (SIGKILL)
	sinal 15 — salva e fecha, presumindo que o processo responda (SIGTERM); vale notar que este é o sinal padrão, caso nenhum seja especificado
	sinal 19 — congela o processo (SIGSTOP)
	sinal 18 — continua um processo que havia sido congelado (SIGCONT)

killall [tipo de sinal, precedido por traço] [termo] — faz o mesmo que o kill, mas envia o sinal de forma simultânea para todos os processos cujo nome tenha um determinado termo

apt OU apt-get — diferentes comandos usados para chamar o gerenciador de pacotes do Debian, o que é necessário para realizar certas ações
	[...] install [nome de um pacote] — instala um pacote
		[...] install -f — baixa dependências que estejam faltando para pacotes instalados no sistema
	[...] update — atualiza o gerenciador de pacotes para garantir que todos os pacotes estejam na versão mais recente
	[...] upgrade — atualiza todos os pacotes que já foram baixados
	[...] search [termo] — busca pacotes por palavra-chave
	[...] remove [nome de um pacote já instalado] — deleta um pacote, mantendo seus arquivos de configuração
	[...] purge [nome de um pacote já instalado] — deleta um pacote e seus arquivos de configuração
	[...] autoremove — desinstala todas as dependências que foram baixadas mas não estão mais atreladas a nenhum pacote presente no sistema

clear — limpa a tela do terminal; vale ressaltar que o atalho Ctrl + L faz a mesma coisa

info [nome de um comando] OU [nome de um comando] --info — versão mais moderna do man, disponível em alguns casos

help [nome de um comando] OU [nome de um comando] --help — instruções mais simplificadas (em relação a man e info) sobre um comando; porém, está disponível apenas em alguns casos, e o uso de help ou --help é dependente da situação específica

reset — reinicia o terminal caso tenha ocorrido algum problema

ifconfig — comando obsoleto pra visualizar e gerenciar interfaces de rede do computador (interface configuration)
	ifconfig [nome da interface] down — desativa uma interface
	ifconfig [nome da interface] up — ativa uma interface
	ifconfig [nome da interface] [endereço IP] — configura um endereço IP manualmente

netstat — comando obsoleto pra visualizar e gerenciar conexões de rede ativas (network statistics); os parâmetros são os mesmos da versão mais moderna, que é o ss, exceto por um
	netstat -r — ver o IP do roteador sendo utilizado (o equivalente moderno faz parte do comando ip)

dpkg — gerenciador de pacotes obsoleto do Debian; funciona de forma similar ao apt
	dpkg -i [nome de um pacote] — instala um pacote
	dpkg -r [nome de um pacote já instalado] — desinstala um pacote
	dpkg -l — lista todos os pacotes instalados no sistema
	dpkg -S [nome de um arquivo] — mostra qual programa instalou um determinado arquivo

pwd — mostra o diretório atual (print working directory)
	pwd -P — caso o diretório atual seja um atalho, mostra a localização real dentro do sistema

cat [nome de um arquivo] — lê e exibe o conteúdo de um arquivo (catenate)
	cat > [nome de um arquivo a ser criado] — cria um arquivo e abre-o pra edição
	cat [nome de um arquivo] [nome de outro arquivo] > [nome de um arquivo a ser criado] — concatena o conteúdo de dois arquivos em um novo arquivo
	cat -n [nome de um arquivo] — mostra o número das linhas durante a exibição
	cat -E [nome de um arquivo] — destaca o fim de cada linha do arquivo com um cifrão
	cat -s [nome de um arquivo] — remove linhas em branco sequenciais durante a exibição de um arquivo (mantendo apenas uma por trecho)

users — mostra todos os usuários logados no sistema

adduser [nome de um usuário a ser criado] OU useradd [nome de um usuário a ser criado] — adiciona um novo usuário no sistema (o primeiro comando é mais moderno e permite interatividade)
	useradd -m [nome de um usuário a ser criado] — cria uma pasta home pro novo usuário (isso acontece por padrão no adduser)
	useradd -s [caminho do terminal a ser usado] [nome do usuário a ser criado] — define qual terminal o usuário novo utilizará (isso é definido por padrão no adduser)

history — mostra todos os comandos inseridos durante uma sessão, mesmo após um clear
	history -d [número de um comando] — apaga um comando do histórico
	history -c — apaga o histórico inteiro
	history -w — salva quaisquer alterações feitas no histórico

![número de um comando inserido anteriormente] — repete um comando (o número é visto através do history)

ip — comando moderno pra visualizar e gerenciar interfaces de rede do computador
	ip a OU ip address — lista todas as interfaces atuais e mostra seus endereços de IP
	ip link set dev [nome da interface] down — desativa uma interface
	ip link set dev [nome da interface] up — ativa uma interface
	ip r OU ip route — mostra o IP do roteador sendo utilizado
	ip addr add [endereço de IP a ser utilizado] dev [nome da interface] — configura um endereço de IP para uma determinada interface manualmente

ss — comando moderno pra visualizar e gerenciar conexões de rede ativas (socket statistics)
	ss -t — mostra conexões TCP
	ss -u — mostra conexões UDP
	ss -l — mostra apenas conexões em modo listening (que estejam esperando conexões de fora)
	ss -n — exibe informações de forma numérica (por exemplo, mostrando números específicos de portas ao invés de seus nomes)
	ss -p — mostra os programas que são donos das conexões
	ss -a state established — mostra apenas conexões que estejam trocando dados (ou seja, que não estejam esperando); a significa "todas as conexões", ao invés de apenas TCP ou UDP
	ss -tua dst :[número de uma porta] — mostra quem está utilizando uma determinada porta
	ss -s — mostra um resumo

nano [nome de um arquivo, seja ele já existente ou novo] — abre o editor nano pra criar ou modificar um arquivo

vi [nome de um arquivo, seja ele já existente ou novo] — abre o editor vi pra criar ou modificar um arquivo
	dentro do vi:
		Esc — abre o modo de comandos
		i — abre o modo de inserção
		:w (no modo de comandos) — salva sem sair
		:wq (no modo de comandos) — salva e sai
		:q (no modo de comandos) — sai do arquivo (aceito apenas se não houver nenhuma alteração)
		:q! (no modo de comandos) — força a saída
		u (no modo de comandos) — desfaz a última alteração
		dd (no modo de comandos) — corta a linha atual (pode ser precedido por um número pra cortar múltiplas linhas simultaneamente)
		yy (no modo de comandos) — copia a linha atual (pode ser precedido por número)
		p (no modo de comandos) — cola a linha copiada abaixo da posição do cursor (pode ser precedido por número)
		P (no modo de comandos) — cola a linha copiada acima da posição do cursor (pode ser precedido por número)
		h, j, k, l (no modo de comandos) — movem o cursor pela tela
		:%s/[palavra a ser substituída]/[nova palavra]/g (no modo de comandos) — substitui todas as instâncias de uma determinada palavra por outra
		xxd (no modo de comandos) — ativa a edição em hexadecimal, o que é recomendado pra arquivos binários

less [nome de um arquivo] — faz a mesma coisa que o cat, mas em exibição paginada

tail [nome de um arquivo] — similar ao cat e ao less, mas mostra apenas as 10 últimas linhas do arquivo
	tail -n [número de linhas] [nome de um arquivo] — mesma coisa, mas permite definição manual da quantidade de linhas a serem lidas (20 últimas linhas, por exemplo)
	tail -f [nome de um arquivo] — mantém o arquivo aberto no terminal para que linhas novas sejam exibidas conforme forem criadas

head [nome de um arquivo] — faz a mesma coisa que o tail, mas mostrando as 10 primeiras linhas do arquivo; possui os mesmos parâmetros
	head -n [...] | tail -n [número de linhas; não é necessário reinserir o nome do arquivo depois] — truque pra mostrar um intervalo de linhas específico

whoami — mostra o nome do usuário controlando o terminal

who — parecido com o users, mas mostra mais detalhes
	who am i — mostra o nome do usuário que fez o login inicial na máquina

w — parecido com o who, mas mostra ainda mais detalhes

deluser [nome do usuário] OU userdel [nome do usuário] — deletam um usuário (o primeiro comando é mais moderno)
	deluser --remove-home [...] — deleta o usuário e também sua respectiva pasta home
	deluser --backup [...] — faz um backup dos dados do usuário antes de excluir
	userdel -r [...] — deleta o usuário e também sua respectiva pasta home

mount — por si só, exibe todos os dispositivos atualmente montados no sistema; porém, sua função principal é permitir a montagem de novos dispositivos
	mount [arquivo especial que corresponde ao dispositivo inserido] [pasta que receberá a montagem] — monta um novo dispositivo

umount [arquivo especial do dispositivo] OU umount [pasta de montagem do dispositivo] — desmonta um dispositivo

tar [parâmetros] [nome do arquivo tar a ser criado, ou de um arquivo tar já existente caso seja realizada uma extração] [conteúdo que se deseja concatenar, seja uma sequência de arquivos ou um diretório, caso aplicável] — concatena vários arquivos em um novo arquivo .tar ou extrai o conteúdo de um arquivo .tar já existente
	parâmetros:
		-c — cria um arquivo .tar
		-x — extrai o conteúdo de um arquivo .tar
		-v — modo verboso (mostra na tela os arquivos sendo processados, individualmente)
		-f — deve ser sempre o último, e indica que o nome de um arquivo será passado em seguida
		-z — usa o gzip, seja pra compactar ou descompactar (durante uma extração); vale ressaltar que outros algoritmos de compactação existem, e necessitam de comandos próprios
		-t — visualiza os arquivos contidos dentro de um .tar sem extrair (ou seja, alternativa ao c e ao x, de uso um pouco mais incomum)

/etc/resolv.conf — este não é um comando, e sim um arquivo contendo os servidores de DNS utilizados pelo sistema

./[nome de um arquivo .sh] — executa um arquivo .sh (shell script)

#!/bin/bash — chamado de shebang, é obrigatório no começo de um arquivo .sh pra indicar o interpretador a ser utilizado (neste caso, o padrão, que é o bash; para usar outro, basta trocar "bash" pelo interpretador correspondente)

echo [texto] — repete na tela do terminal um texto que tenha sido inserido
	echo $[nome de uma variável] — exibe o conteúdo de uma determinada variável
	echo [texto] > [nome de um arquivo] — coloca um determinado texto dentro de um arquivo (se o arquivo não existia, ele é criado; se o arquivo já existia e tinha conteúdo, esse conteúdo é sobrescrito)
	echo [texto] >> [nome de um arquivo já existente] — adiciona um determinado texto ao final do conteúdo de um arquivo
	echo -e [...] — imprime \n literalmente (caso contrário, é quebra de linha)
	echo -n [...] — não pula pra próxima linha após o fim do comando

sleep [quantidade de tempo; segundos por padrão, pode ser especificado com s, m, h ou d na sequência] — faz o terminal pausar por um tempo antes de permitir o próximo comando

bash — possui várias funções; por si só, cria um subterminal, que pode ser fechado com exit
	bash [nome de um arquivo .sh] — executa um shell script mesmo que ele não possua permissão de execução (o que é o padrão, precisando de alteração através do chmod)
	bash -c [linha de código, podendo conter vários comandos em sequência; entre aspas, e os comandos devem ser separados por ponto e vírgula] — executa uma linha de código sem necessitar de um arquivo .sh

passwd — comando interativo pra mudar a senha do usuário que o executou
	passwd [nome do usuário] — pode ser utilizado pelo superusuário pra mudar senhas de outros usuários
	passwd -l [nome do usuário] — comando de superusuário pra bloquear acesso a uma conta por usuários comuns, mesmo que saibam a senha
	passwd -u [nome do usuário] — comando de superusuário que desbloqueia o acesso a uma conta
	passwd -e [nome do usuário] — faz com que a nova senha seja temporária e precise ser trocada imediatamente após o login do usuário

systemctl — comando utilizado pra interagir com o gerenciador do sistema
	systemctl status [nome de um serviço] — mostra o status de um serviço
	systemctl start [nome de um serviço] — liga um serviço
	systemctl stop [nome de um serviço] — desliga um serviço
	systemctl restart [nome de um serviço] — reinicia um serviço
	systemctl reload [nome de um serviço] — recarrega configurações de um serviço sem desligá-lo
	systemctl enable [nome de um serviço] — configura um serviço para que ele seja inicializado sempre que o computador for ligado
	systemctl disable [nome de um serviço] — faz o contrário do enable
	systemctl list-units --type=service — lista todos os serviços ativos na máquina
	systemctl is-active [nome de um serviço] — verifica se um serviço está ativo
	systemctl --failed — mostra todos os serviços que tentaram inicializar e sofreram falhas
	systemctl reboot — reinicia a máquina
	systemctl poweroff — desliga a máquina

journalctl — comando utilizado para consultar logs do sistema
	journalctl -u [nome de um serviço] — consulta logs de um determinado serviço
	journalctl -f — consulta logs em tempo real conforme eles aparecem (similar ao tail -f)
	journalctl --since [data] — consulta todos os logs desde uma determinada data (seja ela especificada manualmente ou através de um termo em inglês como "today", "yesterday" e "1 hour ago")
	journalctl --until [data] — consulta todos os logs até uma determinada data 
	journalctl -p [nível de alerta; pode ser nome ou número] — consulta logs pertencentes a um determinado nível de alerta (vai de 0 a 7)
	journalctl -b — mostra apenas os logs do boot atual (para mostrar os logs dos n últimos boots, a sintaxe é journalctl -b -[quantidade n de boots anteriores ao atual])
	journalctl --disk-usage — mostra quanto espaço os logs ocupam
	journalctl --vacuum-size=[quantidade n de espaço] — deleta todos os logs do mais antigo pro mais recente, até sobrar apenas uma quantidade n de logs determinada por espaço (por exemplo, 500MB, que aqui seria 500M)
	journalctl --vacuum-time=[quantidade n de tempo] — similar ao vacuum-size, mas baseado em tempo (por exemplo, "2weeks" pra manter os logs das duas últimas semanas)

apache2ctl — comando específico do Apache, para fins de gerenciamento
	apache2ctl configtest OU httpd -t — confira se quaisquer alterações feitas estão com a sintaxe correta antes de efetivá-las
	apache2ctl -S — lista todos os sites que estão sendo hospedados
	apache2ctl -M — lista todos os módulos ativos
	apache2ctl start — inicia o servidor
	apache2ctl stop — para o servidor
	apache2ctl restart — reinicia o servidor
	apache2ctl graceful — recarrega as configurações do servidor sem pará-lo

a2ensite [arquivo contendo as configurações de um site] — ativa um site com o Apache

a2dissite [arquivo contendo as configurações de um site] — desativa um site com o Apache

a2enmod [módulo do Apache] — ativa um determinado módulo do Apache

a2dismod [módulo do Apache] — desativa um determinado módulo do Apache

função dos diretórios padrão:
	/ – diretório raiz, contendo todos os outros
	/bin – contém os arquivos da maioria dos comandos acessíveis para todos os usuários
	/boot – contém os arquivos do kernel e do boot (inicialização) do sistema
	/dev – contém os arquivos referentes aos dispositivos externos
	/etc – contém os arquivos de configuração do sistema
	/home – contém diretórios pessoais dos usuários
	/lib – contém bibliotecas utilizadas pelos arquivos do diretório /bin
	/mnt – diretório de montagem (comando mount)
	/proc – contém informação sobre processos ativos
	/root – diretório raiz do usuário root
	/sbin – contém os arquivos dos comandos de superusuário
	/tmp – contém arquivos temporários, que são deletados se o sistema for desligado ou reiniciado
	/usr – contém os arquivos executáveis dos programas do sistema
	/var – contém arquivos variáveis, geralmente criados para armazenar informações de programas (cache, login de usuário, etc.)

cores no terminal:
	azul escuro – diretório
	amarelo – arquivo de dispositivo externo
	verde – executável
	ciano – link simbólico (arquivo que aponta para outro arquivo ou diretório)
	rosa – imagem/vídeo
	branco – arquivo regular
	vermelho – arquivo comprimido

/etc/shadow – arquivo que contém a senha (criptografada) de todos os usuários do sistema

informações sobre o Apache:
	ServerRoot – é o diretório que serve como base pro Apache no sistema, com todos os caminhos relativos sendo calculados a partir dele; seu valor padrão é /etc/apache2
   	MaxClients (ou MaxRequestWorkers, em versões mais recentes do Apache) – define o número de requisições simultâneas que o Apache pode atender; o valor padrão costuma estar na faixa entre 150 e 250
  	User e Group – são o usuário e o grupo, respectivamente, que controlam o Apache; o valor padrão é www-data para ambos, mas ele inicia como root para poder usar a porta 80
   	ServerAdmin – é o endereço de email exibido aos usuários caso haja um erro; o valor padrão é webmaster@localhost
   	DocumentRoot – é a pasta onde os arquivos do site serão armazenados por padrão, para serem enviados ao navegador; seu valor padrão é /var/www/html

df – mostra o espaço em disco disponível (pode ser sucedido pelo nome de um arquivo ou diretório específico para verificar apenas ele)
	df -h – exibe o tamanho em formato human-readable (MB, GB...) ao invés de Kbytes
	df -T – exibe o sistema de arquivos que foi utilizado pra formatar a partição
	df -i – mostra a quantidade de Inodes (espécie de ID utilizada para determinar quantos arquivos podem existir no sistema) disponíveis

du – mostra o tamanho do diretório atual (pode ser sucedido pelo caminho de um diretório específico para verificar ele)
	du -s – exibe o resultado de forma resumida
	du -h – exibe em formato human-readable (como no df)

sort – exibe algo em ordem alfabética
	sort -n – ao trabalhar com números, exibe-os em ordem ascendente (isto é, 10 não será mostrado antes de 2, por exemplo)
	sort -r – inverte a ordem e mostra de forma descendente
	sort -u – tira todos os valores duplicados
	sort -f – ignora case sensitivity (caso contrário, maiúsculas aparecem antes de minúsculas)
	sort -o [arquivo com a informação original] [novo arquivo] – copia a informação de um arquivo para outro, mas na ordem correta após passar pelo sort

mv [nome de um arquivo] [diretório de destino] – move um arquivo de lugar
	mv [nome de um arquivo] [nome novo para o arquivo] – renomeia o arquivo
	mv -i [...] – se houver um arquivo com mesmo nome no destino, pergunta se deseja sobrescrever (por padrão, sobrescreve)
	mv -n [...] – não sobrescreve caso haja um arquivo com mesmo nome no destino
	mv -b [...] – similar ao -n, mas renomeia o arquivo antigo adicionando ~ ao final
